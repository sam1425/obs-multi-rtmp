# Auto Multiple RTMP 

A plugin for obs fork from [sorayuki's work](https://github.com/sorayuki/obs-multi-rtmp) that automatically starts all added sources when the main stream is started,
this is done exposing a function through c/cpp and activating it from a python script(just a termporary solution until i figure out how event listeners work on cpp).


You can donate to soruyaki through their mehtod listed [here](https://github.com/sorayuki/obs-multi-rtmp).

# Usage

1. Download and install the plugin.
2. Download and insert the python scriptl.
3. Enjoy it.

## Build

This project uses obs-plugintemplate.   
Please refer to obs-plugintemplate to understand how it works.
